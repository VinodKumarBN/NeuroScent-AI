# NeuroScent-AI
Early-Stage Neurodegenerative Screening System

NeuroScent AI is an experimental screening prototype that utilizes temporal olfactory rhythm analysis to detect potential markers of neurodegenerative decline. By processing inhalation patterns via an AI-driven LSTM-Autoencoder model, the system quantifies physiological anomalies that may precede clinical symptom onset.

🧠 Project Overview
Neurodegenerative diseases like Alzheimer's and Parkinson's are often diagnosed only after significant progression. NeuroScent AI provides a non-invasive, accessible, and scalable solution to screen for these conditions by analyzing rhythmic olfactory stability through smartphone-based audio analysis.

🚀 Key Features
AI-Driven Diagnostics: Uses an LSTM-Autoencoder logic to analyze inhalation consistency and peak intensity.

Longitudinal Tracking: Integrated dashboard to monitor "Reconstruction Error Index" trends over time.

Non-Invasive: Eliminates the need for traditional, high-cost medical imaging for initial screening.

User-Friendly Interface: Built with Gradio for intuitive, real-time diagnostic outputs.

🛠 Tech Stack
Language: Python 3.12+

Framework: Gradio (for UI/UX)

Data Handling: Pandas, NumPy

Architecture: LSTM-Autoencoder (Simulation)

💻 How to Run
Clone the repository:

Bash
git clone https://github.com/VinodKumarGgithub/NeuroScent-AI.git
cd NeuroScent-AI
Install dependencies:

Bash
pip install gradio pandas
Run the application:

Bash
python app.py
Access the UI: Open the provided local URL (usually http://127.0.0.1:7860) in your browser.
